# 96. 시간표 없는 노선을 실측으로 채우기

- 무엇을 만들었나: `TimetableService`가 공식 시간표가 비고 1~9호선이 아니면 실측 시간표로 내려간다. 열차마다 `source`(`official`·`measured`)를 달아, `/timetable` 응답, 실시간 대체 그룹, 경로의 환승 열차까지 출처가 이어진다.
- 왜 이렇게 했나 (검토한 대안과 고른 이유):
  - 출처를 열차에 달았다. 응답마다 따로 계산하면 세 곳(시간표, 도착, 경로)에서 같은 판단을 반복해야 한다.
  - 1~9호선은 실측이 있어도 공식을 쓴다. 공식이 운행표 그 자체라 더 정확하고, 실측은 아직 평가 전이다.
- 막혔던 점과 해결:
  - 역 코드가 없는 노선은 예전엔 바로 빈 목록이었다. 코드가 없어도 실측으로 내려가도록 순서를 바꿨다(비서울 노선만 바로 빈 목록).
- 예상 면접 질문과 내 답:
  - Q. 응답 형식을 바꿨는데 예전 앱이 깨지지 않나?
  - A. 필드만 더했다. 앱 JSON 파서는 모르는 필드를 무시하고, 출처 문자열도 모르는 값이면 지금처럼 보인다.
