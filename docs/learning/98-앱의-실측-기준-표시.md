# 98. 앱의 "실측 기준" 표시

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: 역 시트의 근거 문구를 참·거짓 하나에서 목록으로 바꿨다("시간표 기준", "실측 기준", 둘 다). 경로 상세의 환승 열차가 실측이면 "(실측)"을 붙인다.
- 왜 이렇게 했나 (검토한 대안과 고른 이유):
  - 한 역에 1~9호선과 시간표 없는 노선이 같이 있으면(예: 공덕) 공식과 실측이 섞인다. 하나만 보이면 틀린 근거를 말하게 된다.
  - 실측이 있는 노선은 "시간표를 제공하지 않는 노선" 안내에서 자연히 빠진다(열차가 있으므로).
- 막혔던 점과 해결:
  - 기존 테스트 세 곳이 옛 이름(`fromTimetable`)을 썼다. 목록 비교로 바꿨다.
- 예상 면접 질문과 내 답:
  - Q. 왜 "예측"이 아니라 "실측"이라고 쓰나?
  - A. 지금 값은 실제로 관측한 출발 시각의 중앙값이다. 모델이 지연을 더해 계산하는 단계(M1)가 오면 그때 "예측"을 쓴다.
