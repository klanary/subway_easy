# 20. 경로 상세 지도와 단계 안내

- 무엇을 만들었나: 경로 상세 화면. 위는 구간별 색 경로선(도보 회색 점선, 지하철 호선 색, 버스 초록)과 출발·환승·도착 마커를 그린 지도, 아래는 끌어 올리는 시트(`BottomSheetScaffold`)에 단계 안내("2호선 홍대입구 → 당산 · 2정거장", "도보 7분").
- 왜 이렇게 했나 (검토한 대안과 고른 이유):
  - 무엇을 그릴지 정하는 일(`buildOverlay`: 선·마커·카메라 범위)과 SDK로 실제 그리는 일(`KakaoMap.render`)을 나눴다. 앞쪽은 순수 함수라 지도 없이 단위 테스트하고, SDK 호출만 하는 뒤쪽은 실기기에서 확인한다.
  - 환승 마커는 두 번째 대중교통 단계부터 각 단계의 첫 좌표에 찍는다. 첫 대중교통 탑승 지점은 출발 마커와 가깝고, "갈아타는 곳"만 눈에 띄게 하려는 것이다.
  - 도보 점선은 SDK의 선 패턴(작은 점 이미지를 일정 간격으로 찍음)으로 그렸다. 선 자체는 투명하게 두어 점만 보인다.
  - 마커 이미지는 XML 도형(drawable)으로 두고 비트맵으로 바꿔 라벨로 찍는다. 색·크기를 리소스에서 바로 고칠 수 있다.
  - 앱이 백그라운드에서 정리돼 검색 결과가 사라졌으면, 빈 지도 대신 "경로를 다시 검색해 주세요"를 보여준다.
- 막혔던 점과 해결:
  - 개발 PC에 기기가 없어 실제 지도 위의 선·마커 모양은 확인하지 못했다. 그림의 내용(선 색·점선 여부·마커 위치)은 테스트로 고정했다.
- 예상 면접 질문과 내 답:
  - Q. 지도 SDK 코드는 어떻게 테스트하나요? A. SDK에 의존하지 않는 "무엇을 그릴지" 모델을 만들어 테스트하고, SDK 호출은 그 모델을 그대로 옮기는 얇은 함수로 둔다. 얇은 함수는 실기기 체크리스트로 확인한다.
