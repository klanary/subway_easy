# 54. 위치 결합·열차 추적을 걷어 내고, 하차 알림은 켰을 때만

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: 위치로 탑승 감지, 탄 열차 실시간 추적, 열차 직접 고르기를 지웠다(재설계 D1). 세션 서비스는 대기 단계의 도착 조회만 하고 유형은 `dataSync` 하나다. 대기 세션에 `alightAlerts`를 더해, [탑승했어요] 뒤 환승·하차 알림은 사용자가 진동 알림을 켰을 때만 이어 간다(D2). 꺼져 있으면 탑승으로 세션이 끝난다.
- 왜 이렇게 했나:
  - 목표가 "간단한 앱"이다. 추적은 두 호선만 됐고 위치 권한·포그라운드 서비스 유형·Android 14 제약 같은 복잡도가 컸다.
  - 탑승 뒤에는 알람(`setAlarmClock`)만으로 하차 알림을 울린다. 그래서 탑승 단계에는 서비스를 켜지 않는다(재설계 스펙 5.5).
  - 상태 머신 하나를 두 번 고치지 않으려고 추적 제거(A2)와 진동 알림 조건(A8)을 함께 했다.
- 막혔던 점과 해결:
  - 기기에 저장된 옛 세션 JSON에는 `tracking` 칸이 있다. `ignoreUnknownKeys`로 그대로 읽히는지, `alightAlerts` 칸이 없는 옛 대기 세션은 false로 읽히는지 테스트로 확인했다.
  - 세션 화면 목적지는 인자(`pickTrain`)가 없어져 `object SessionDest`로 되돌렸다.
- 예상 면접 질문과 내 답:
  - Q. 알림 권한이 없으면? A. 기존처럼 앱 안 모드로 이 화면이 보이는 동안 대기 조회와 알람 확인을 대신 돌린다.
