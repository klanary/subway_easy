# 서울시 지하철 API 알려진 이슈 점검

서울 열린데이터광장 개발자 댓글(약 1년치)을 요약한 목록을 **2026-11-22 낮(11~12시) 실제 응답**으로 하나씩 대조했다.
분류 기준은 다음과 같다.

- **고친 이슈(원천)**: 지금 응답이 제대로 나온다. 옛날에 원천에서 고친 것으로 보고 따로 처리하지 않는다.
- **고친 이슈(우리)**: 지금도 재현되어 서버에서 처리했다.
- **여전함**: 원천에서 아직 고쳐지지 않았다. 앱은 대신할 방법으로 보인다.
- **미확인**: 확인할 수 없었다(시간대 등).

## 고친 이슈(원천) — 지금 제대로 나온다

| 이슈 | 2026-11-22 확인 결과 |
|---|---|
| 당고개 → 불암산 역명 변경 | 실시간 응답의 역 이름이 `불암산`으로 온다(4호선, 정상 문구). 옛 이름 검색은 우리 쪽에서 별칭으로 더했다(아래). |
| GTX-A 수서~동탄 데이터 누락 | 수서·구성·동탄 모두 GTX-A(1032) 행이 온다. 도착 코드·문구도 정상. |
| 경춘선 광운대 관련 역 ID 누락 | 광운대·상봉·청량리 응답에 `statnId` 빈 칸이 없다. (지금 광운대에는 경춘선 행이 오지 않고 1호선만 온다.) |
| 김포공항 `trnsitCo` 불일치 | 모든 행이 `trnsitCo` 4로 같다. 우리 앱은 이 값을 쓰지 않는다. |
| 5호선 강일~하남검단산 상태 제한 | 강일·미사·하남풍산·하남시청·하남검단산 모두 `전역 도착`, `[N]번째 전역`, 도착 코드 1·5·99가 온다. 세부 상태가 들어오고 있다. |
| 시청·서울역 1호선 하행이 앞부분에 없음 | 우리는 처음부터 50건을 받는다. 두 역 모두 1호선 하행이 보인다. |
| 열차 위치 API의 `statnTid`는 종착역 | 우리 수집기(`server/ml/parse.py`)는 `statnTid`·`statnTnm`을 종착역으로 읽고 있다. 처리할 것 없음. |

## 고친 이슈(우리) — 재현되어 서버에서 처리

| 이슈 | 재현 내용 | 처리 |
|---|---|---|
| 같은 역도 노선마다 조회 이름이 다름 | 서울역 GTX-A는 `서울역`으로만, 신촌 경의중앙선은 `신촌(경의중앙선)`으로만 온다. | 노선 전용 이름으로 따로 묻고 합친다(`LINE_API_NAMES`). |
| 경의중앙선 서울역·신촌 지선에 본선 열차가 섞임 | 두 역 모두 팔당·지평행이 왔다. | 덕소·팔당·용문·지평·청량리·용산행을 뺀다(`BRANCH_SKIP`). |
| 조회한 역이 아닌 역의 행 | 지금은 재현되지 않았다. 조회 이름 653개 모두 `statnNm`이 조회 이름과 같다. | 다른 역 행을 빼는 필터를 예방으로 넣었다. |
| 이 역에서 끝나는 열차 | 서울역 공항철도 "서울행 전역 출발", 광운대 1호선 "광운대행 광운대 도착". | 종착이 이 역인 열차를 뺀다. |
| 같은 열차가 두 행으로 옴 | 지금은 재현되지 않았다. | 노선·방향·열차 번호가 같으면 가장 최근 행 하나만 둔다. |
| `barvlDt`가 계속 0(코레일 원천) | 1호선 68행 가운데 67행, 4호선 코레일 구간·경의중앙선·공항철도·경춘선·수인분당선도 거의 다 0이다. | 원래 `arvlMsg2`로 추정하고 있었다(못 읽은 문구 0개). 못 읽을 때를 대비해 `arvlCd` 추정을 더했다. |
| 옛 이름 당고개로 검색 | 검색 결과가 비었다. | 별칭 `당고개 → 불암산`을 더했다. |

## 여전함 — 원천이 아직 그대로

| 이슈 | 2026-11-22 확인 결과 | 앱의 처리 |
|---|---|---|
| 4호선 진접·오남·별내별가람 실시간 미연계 | 세 역 모두 `INFO-200`(데이터 없음). | 4호선 공식 시간표로 대신 보인다(진접에서 확인). |
| 인천 1·2호선 실시간 미연계 | 인천시청·예술회관 `INFO-200`. | "실시간 정보 미제공"으로 보인다. |
| 1호선 공식 시간표 없음(시간표 API) | 11-22 01:30부터 1호선 102개 역 모두 `INFO-200`(어떤 키든 같다). 11-21까지는 왔다. | 11-21에 받아 둔 사본으로 답한다(`server/data/official_snapshot.json.gz`). |

## 미확인

- **2호선 막차 표시(`lstcarAt`) 오류**: 막차 시간대에만 확인할 수 있다. 밤에 다시 본다.
- **신분당선 미래 `recptnDt`**: 서버는 미래 시각이면 지난 시간을 빼지 않는다(이미 처리). 이번 점검에서 다시 보지는 않았다.

## 아직 남은 우리 쪽 문제

- ~~실측 시간표가 낮에 다음 날 첫차("05:00 출발")를 다음 열차로 준다~~ → 고침. 원인: 실측 결과물(as_of 11-21)에 주말(요일 구분 2·3) 칸이 아직 없고, GTX-A 평일 6~24시는 변경 의심으로 빠져 있었다. 오늘 요일 칸이 없거나 앞으로의 시간대가 빠져 있으면 "모름"(빈 목록)으로 두고, 다음 날 첫차는 막차가 지난 밤에만 준다.
- 열차가 빠졌을 때 원본 응답을 남기는 기록이 없다.
