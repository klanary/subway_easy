# 학습 노트

구현 작업이 끝날 때마다 노트를 하나 남긴다(스펙 12절). Claude Code가 초안을 쓰더라도 본인이 직접 고쳐 쓴다.

## 번호 규칙

- 파일 이름은 `NN-주제.md`다. NN은 이 폴더에 있는 가장 큰 번호 + 1이고, 두 자리로 쓴다(예: `01-최소-서버.md`).
- 코드를 바꾸는 작업은 그 커밋에 노트 초안을 함께 넣는다.

## 형식

```markdown
# NN. 주제
- 무엇을 만들었나:
- 왜 이렇게 했나 (검토한 대안과 고른 이유):
- 막혔던 점과 해결:
- 예상 면접 질문과 내 답:
```
