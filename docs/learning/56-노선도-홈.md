# 56. 노선도 홈 화면

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: 시작 화면을 노선도로 바꿨다. AndroidSVG로 노선도를 한 번 `Picture`로 그려 두고, Compose `Canvas`에서 이동·배율만 바꿔 다시 그린다. 끌기, 두 손가락 확대·축소, 두 번 누르면 2배, 역 누르기(24dp 안 가장 가까운 역). 위에 역 검색·경로 찾기·현재 위치·설정, 아래에 접히는 패널([루틴] [자주 가는 경로]).
- 왜 이렇게 했나:
  - 좌표 계산(`MapTransform`: 화면 = 지도 × 배율 + 이동, `zoomAround`, `hitStation`)을 순수 함수로 떼어 기기 없이 테스트한다.
  - SVG를 매 프레임 해석하지 않고 `Picture`로 한 번만 만든다. 이후에는 캔버스 변환만 바꾸므로 빠르다.
  - 누르기 반경은 화면에서 24dp라 지도 좌표로는 `24dp / 배율`이다. 확대할수록 지도에서의 반경이 줄어 이웃 역을 잘못 고르지 않는다.
  - 배율 하한은 노선도 전체가 화면에 들어가는 값, 상한은 역 이름이 약 24dp가 되는 값이다. 스펙의 "0.5배~4배"는 이 화면에서 글자가 읽히는 범위로 바꿔 정했다.
- 막혔던 점과 해결:
  - 노선도 위치표를 백그라운드에서 읽어 테스트가 기다리지 못했다. 읽는 디스패처를 생성자로 받아 테스트에서는 Main(테스트 디스패처)을 준다.
- 예상 면접 질문과 내 답:
  - Q. 노선도에 없는 역(원곡 등)에서 [현재 위치]를 누르면? A. "노선도에 없는 역이에요"를 잠깐 보인다.
