# 55. 노선도 역 위치 뽑기

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: 위키미디어 공용 노선도 SVG에서 역 이름 글자의 위치를 읽어 우리 역 id에 잇는 `scripts/build_linemap.py`. 결과는 앱 자산 `linemap/stations.json`(역 id, x, y)과 SVG 원본이다.
- 왜 이렇게 했나:
  - 노선도를 직접 그리면 디자인에 시간이 많이 든다. 퍼블릭 도메인 노선도를 그대로 쓰고, 누를 수 있는 점만 뽑으면 된다(재설계 D8).
  - 글자 기준점은 역 표시에서 조금 떨어져 있다. 70px 안의 가장 가까운 역 표시(환승역 기호, 짧은 눈금 선)에 붙여 누르는 점을 역 위에 둔다.
- 막혔던 점과 해결:
  - 노선도의 글자는 모두 `transform="matrix(a b c d e f)"`로 놓여 있다. 이동 값(e, f)을 기준점으로 썼다. 묶음(`<g>`) 변환은 없었다.
  - 같은 이름 "양평"이 두 곳(5호선, 경의중앙선)에 있다. 우리 데이터의 경도 순서와 노선도의 x 순서를 맞춰 동서로 나눴다.
  - 이름이 다른 역(자양 = 뚝섬유원지, 평택지제 = 지제, 용인중앙시장 = 김량장)과 가운뎃점(·/.)을 맞췄다. 우리 데이터에는 두 역인 총신대입구·이수는 같은 자리로 둔다.
  - 결과: 우리 역 655개 중 652개(99.5%)를 이었다. 판정 기준(95%)을 넘어 대안(좌표로 직접 그리기)은 쓰지 않는다. 노선도에 없는 역은 운동장.송담대, 원곡, 화전이다.
- 예상 면접 질문과 내 답:
  - Q. 노선도가 바뀌면? A. 새 SVG를 넣고 스크립트를 다시 돌린다. 같은 입력이면 같은 결과가 나오고, 95% 기준은 테스트가 지킨다.
