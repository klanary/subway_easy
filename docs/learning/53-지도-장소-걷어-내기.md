# 53. 지도·장소를 걷어 내고 역 기반 API로

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: 카카오 지도 SDK, 지도에서 고르기, 장소 검색, 내 장소, 즐겨찾는 역을 앱에서 지웠다. 경로의 출발·경유·도착은 `Endpoint`(좌표) 대신 `StationRef`(역 id, 이름)다. 서버의 새 API(가까운 역, 시간표, 역 id 경로, `departAt`)를 쓰는 저장소 함수를 더했다.
- 왜 이렇게 했나:
  - 재설계(D5, D6)로 지도와 장소가 필요 없어졌다. 지도 SDK는 네이티브 라이브러리라 APK 크기와 테스트 설정(Robolectric에서 초기화 실패)에 부담이었다.
  - 경로 지점이 역 id면 서버 캐시 키, 자주 가는 경로 비교, 최근 검색이 모두 id 비교 하나로 끝난다. 좌표 반올림 비교가 사라졌다.
  - 아직 배포 전이라 Room 버전을 2로 올리고 마이그레이션 대신 옛 데이터를 지운다(`fallbackToDestructiveMigration(dropAllTables = true)`).
  - "현재 위치" 출발은 서버의 가까운 역 API로 역을 정한다. 2km 안에 역이 없으면 안내 문구만 보인다.
- 막혔던 점과 해결:
  - 지울 기능(좌표 지점)과 바꿀 API(역 id)가 같은 파일들(경로 흐름, 검색, 즐겨찾기)에 걸쳐 있어 두 작업을 한 번에 했다.
  - DTO 테스트는 손으로 쓴 JSON이 아니라 실제 서버 응답(`src/test/resources/server/`)으로 확인한다. 비서울 노선 그룹은 방향이 null이라 `direction`을 nullable로 바꿨다.
- 예상 면접 질문과 내 답:
  - Q. 시각을 서버에 어떻게 보내나? A. 기기 시간대와 관계없이 한국 시간 오프셋을 붙인 ISO 문자열(`2026-11-13T08:00:00+09:00`)로 보낸다. 서버가 그대로 해석한다.
