# 원본 대비 UX 측정

스펙 4.6절의 측정 과제를 원본 앱과 지금출발로 각각 3회 수행한 결과다(성공 기준 S2). 원본 앱은 1주차에, 지금출발은 4주차에 측정한다.

## 측정 규칙

- 앱을 완전히 종료한 상태에서 시작한다.
- 매회 화면을 녹화한다. 녹화 파일은 저장소에 넣지 않는다.
- 탭 수는 녹화를 보고 센다. 글자 입력은 입력란을 누른 탭 1회로 세고, 키보드 입력은 세지 않는다.
- 시간은 첫 탭부터 목표 화면이 보일 때까지다.
- 두 앱에서 같은 출발지·경유지·도착지·역·방향을 쓴다.

## 과제

| # | 과제 | 목표 화면 | 비교 대상 |
|---|---|---|---|
| T1 | 집에서 학교까지 경로 찾기 | 경로 목록 | 카카오맵 |
| T2 | 경유지 1곳을 넣어 경로 찾기 | 경로 목록 | 카카오맵 (경유지를 지원하지 않으면 같은 목적을 이루는 조작 전체) |
| T3 | 특정 역의 특정 방향 다음 열차 확인 | 그 방향의 다음 열차 정보 | 카카오지하철 |
