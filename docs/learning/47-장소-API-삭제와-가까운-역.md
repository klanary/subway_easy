# 47. 장소 API 삭제와 가까운 역 API

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: `/v1/places/search`, `/v1/places/reverse`와 카카오 로컬 클라이언트를 지우고, `GET /v1/stations/nearest?lat=&lng=`을 더했다.
- 왜 이렇게 했나:
  - 재설계(D6)로 출발·도착을 역으로만 고른다. 장소 검색과 주소 변환을 쓰는 화면이 없어졌으니 서버 코드와 카카오 로컬 호출 한도도 함께 지운다. 쓰지 않는 코드는 테스트와 설정만 늘린다.
  - "현재 위치 → 가까운 역"은 서버의 역 데이터만으로 계산한다. 외부 API를 부르지 않으니 캐시와 한도가 필요 없다.
- 막혔던 점과 해결:
  - 호출 한도 목록과 지표 응답을 확인하던 테스트 두 개가 옛 한도 이름을 기대했다. 스펙에서 뺀 API이므로 기대값을 고쳤다.
- 예상 면접 질문과 내 답:
  - Q. 반경 2km 안에 역이 없으면? A. 404가 아니라 `{"station": null}`을 준다. 요청은 정상이고 결과가 없을 뿐이라서다.
