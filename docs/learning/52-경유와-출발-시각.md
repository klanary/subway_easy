# 52. 경유역 합성과 출발 시각 지정

> Claude Code가 쓴 초안이다. 본인이 직접 고쳐 쓴다(스펙 12절).

- 무엇을 만들었나: `/v1/routes`에 `via`(경유역)와 `departAt`(출발 시각)을 더했다. 경유는 출발→경유, 경유→도착 지하철 경로 상위 3개씩을 이어 9개 조합 중 빠른 5개를 준다(`legs` 2개). 출발 시각을 주면 첫 탑승 열차를 시간표로 고르고 경로마다 `departAt`(첫 열차 출발)과 `arriveAt`(도착 예상)을 붙인다.
- 왜 이렇게 했나:
  - 카카오 경로 API에는 경유지가 없다. 두 번 불러 합친다. 구간별로 캐시하므로 같은 구간을 쓰는 다른 요청도 캐시를 나눠 쓴다.
  - 경유역에서 내리는 것은 사용자가 원한 것이므로 환승 횟수에 넣지 않는다.
  - 경로 모양은 출발 시각과 무관하다. 출발 시각은 캐시 키에 넣지 않고 열차만 요청마다 다시 붙인다.
  - 도착 예상 = 첫 열차 출발 + (총 소요 − 탑승 전 걷는 시간). 탑승 뒤 소요는 카카오 값을 그대로 쓴다.
- 막혔던 점과 해결:
  - 시간대 없는 시각(`2026-11-13T08:00`)은 한국 시간으로 본다. 형식이 틀리면 400.
  - 방향을 모르는 첫 탑승(경의중앙선 일부)은 `departAt`·`arriveAt`을 비운다. 틀린 시각보다 빈 값이 낫다.
- 예상 면접 질문과 내 답:
  - Q. 경유 요금을 더해도 되나? A. 경유역에서 나갔다 다시 타면 요금이 따로 나온다고 보고 더했다. 한쪽 요금을 모르면 비운다.
