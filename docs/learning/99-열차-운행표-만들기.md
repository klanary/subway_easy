# 99. 열차 운행표 만들기

- 무엇을 만들었나: VM `ml/trips.py`. 1~9호선 공식 시간표 캐시(역마다 따로 받은 2,712개 파일)를 열차 번호로 다시 묶어 "이 열차는 어느 역에 몇 시"인 운행으로 바꾸고, 같은 정차 순서를 가진 운행끼리 패턴으로 묶는다. 나머지 노선은 실측 시간표로 같은 운행을 만든다.
- 왜 이렇게 했나 (검토한 대안과 고른 이유):
  - 급행은 서는 역에만 시간표 행이 있으므로, 번호로 묶기만 하면 서는 역만 남는다. "서지 않는 급행" 문제를 따로 처리할 필요가 없다.
  - 같은 번호가 3시간 넘게 끊기면 다른 운행으로 나눈다. 2호선처럼 하루에 같은 번호가 두 번 다닐 수 있다.
  - 신분당선처럼 열차 번호가 날마다 바뀌는 노선은 첫 역 출발 시각에 B2 구간 시간을 더해 "어림" 운행을 만든다.
  - 한 패턴 안에서 뒤 열차가 앞 열차를 앞지르면 다른 패턴으로 나눈다. RAPTOR의 이분 탐색이 이 성질에 기댄다.
- 막혔던 점과 해결:
  - 운행표 시각은 "운행일 0시부터 초"로 둬서 24:20 같은 자정 넘김을 그대로 다룬다.
- 예상 면접 질문과 내 답:
  - Q. 왜 서버가 아니라 VM에서 만드나?
  - A. VM은 이미 매일 공식 시간표를 다 받아 두고 메모리도 넉넉하다. 서버는 무료 512MB라 다 만든 결과만 받는다.
